# JAOF FOODS – Fish in Pond

## Small Shop Stock and Sales Tracker

### Project Description
A web-based system designed to manage food production, fish farming, inventory and sales at JAOF FOODS.

### Project Objectives
- Manage raw materials and finished products.
- Record food production activities.
- Monitor fish farming and harvesting.
- Manage fresh and smoked fish inventory.
- Record sales and generate reports.

### Project Methodology
Agile Iterative and Incremental Model.

### Project Duration
10 Weeks.

### Project Type
Individual Academic Project.
